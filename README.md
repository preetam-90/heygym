## ✨ Overview

This project was bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) and is ready to scale — from a weekend side project to a production-grade application.

> 💡 **Why this stack?** Next.js gives you server-side rendering, file-based routing, and first-class TypeScript support out of the box, so you spend less time on boilerplate and more time shipping features.

<div align="center">

| ⚡ Fast Refresh | 🧩 File-based Routing | 🖋️ Optimized Fonts | ☁️ Zero-config Deploys |
|:---:|:---:|:---:|:---:|
| Instant feedback while you code | Just add a file, get a route | Powered by `next/font` | One click via Vercel |

</div>

## 🚀 Getting Started

First, install dependencies and run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Then open **[http://localhost:3000](http://localhost:3000)** in your browser. 🎉

> Start editing by modifying `app/page.tsx` — the page auto-updates as you save.

## 📂 Project Structure

```text
.
├── app/
│   ├── layout.tsx      # Root layout
│   ├── page.tsx        # Home page
│   └── globals.css     # Global styles
├── public/              # Static assets
├── next.config.ts       # Next.js configuration
└── package.json
```

## 🎨 Editing the App

All routes live inside the `app/` directory. Changes to `app/page.tsx` hot-reload instantly — no manual refresh needed.

```tsx
export default function Home() {
  return <h1>Hello, world 👋</h1>;
}
```

---

## 🔤 Fonts

This project automatically optimizes and loads **[Geist](https://vercel.com/font)**, a modern font family crafted by Vercel, using the built-in [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) system for zero layout shift and top-tier performance.
